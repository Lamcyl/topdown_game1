# topdown_game1

A stylized, low-poly, top-down 3D mobile game, built with **Godot 4**. Gameplay is not decided yet.

- [`docs/decisions/0001-game-engine.md`](docs/decisions/0001-game-engine.md): why Godot 4. Covers the options considered, monetization and benchmark results.
- [`benchmark/`](benchmark/README.md): the same test scene in Godot 4 and in three.js (web/Capacitor), for comparing frame rate, heat and battery on real phones.
