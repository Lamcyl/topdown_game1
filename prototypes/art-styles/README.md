# Orbforge art directions

`art-styles.html` is a style board: the same small 3D diorama (floating island, three elemental wells, a conveyor, a fuser cauldron, a ballista, an ogre and a goblin) rendered live with three.js in five candidate art styles:

- Storybook Isles
- Quiet Kingdom
- Painted Tabletop
- Twilight Arcana
- Heraldic Ink

It loads three.js 0.170.0 from jsDelivr, so it needs a network connection to view.

`quiet-kingdom.html` refines the chosen Quiet Kingdom style: ambient occlusion (GTAO, toggleable), rounded and filleted geometry, a fixed camera and a larger 8 × 7 board.
