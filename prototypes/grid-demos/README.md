# Grid gameplay demos

Throwaway 2D placeholder prototypes of four core-loop ideas, each set up as a mid-game fight:

- **Ritual Circle:** lay ritual pieces, then ignite them for combo power against a demon.
- **Wildgrowth:** grow territory and enclose wisps to cut them off from the rot's Heart.
- **Wizard Chess:** summon creatures with chess-like moves to kill the Lich King.
- **Delve:** cross a dungeon floor on a sand budget using found items.

`grid-demos.html` is a single self-contained page (no build step). Open it in a browser, or use the hosted copy linked in the session.

These are plain web prototypes for judging the fun, not game code. The chosen loop will be rebuilt in Godot (see `CLAUDE.md`).
